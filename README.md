## Run Locally

1. Clone the repository:

   ```bash
   git clone https://github.com/basnetsaroj/sarojwebsite.git
   ```

2. Open the project folder:

   ```bash
   cd sarojwebsite
   ```

3. Open `index.html` in a web browser.

No build tools or package installation are required for the basic website.

## Deployment

The website is hosted using GitHub Pages and configured with a custom domain. Updates pushed to the configured publishing branch can be deployed through GitHub Pages.
