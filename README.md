This website showcases my academic background, research projects, engineering skills, professional experience, and achievements. It provides an overview of my work in mechanical engineering, including experimental system development, numerical modeling, and structural vibration analysis.

## Run Locally

1. Clone the repository:

   ```bash
   git clone https://github.com/basnetsaroj/sarojwebsite.git
   ```

2. Navigate to the project directory:

   ```bash
   cd sarojwebsite
   ```

3. Open `index.html` in a web browser.

No build tools or package installation are required to view the basic website.
